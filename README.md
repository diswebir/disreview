# DisReview

افزونه وردپرس برای استایل‌دهی حرفه‌ای و زیبا به بخش **نظرات و کامنت‌ها** در:
- هسته وردپرس (WP Core Comments)
- ووکامرس (WooCommerce Reviews)
- Easy Digital Downloads (EDD Reviews)

بدون تغییر در کد پوسته، فقط با انتخاب یک تم از پنل ادمین.

---

## ویژگی‌ها

- ۶ تم آماده و جذاب: مینیمال، کارتی، حبابی، شیشه‌ای، تیره لوکس، گرادیانی
- پنل ادمین یوزرفرندلی با **پیش‌نمایش زنده**
- فعال‌سازی جداگانه روی ووکامرس / EDD / هسته وردپرس (با تشخیص خودکار نصب بودن)
- انتخاب رنگ اصلی (برند)، گردی گوشه‌ها و فونت سفارشی
- حالت تاریک خودکار (بر اساس تنظیمات سیستم کاربر)
- نمایش امتیاز میانگین روی محصولات
- پشتیبانی کامل RTL
- بارگذاری conditional (فقط در صفحاتی که نظر دارند) برای عملکرد بهتر
- نسخه‌بندی assetها برای کش‌زدایی

---

## نصب

1. پوشه `disreview` را در `wp-content/plugins/` آپلود کنید.
2. از منوی افزونه‌ها آن را فعال کنید.
3. به **تنظیمات » DisReview** بروید و تم و پلتفرم‌های مورد نظر را انتخاب کنید.

---

## رودمپ و فازبندی پیاده‌سازی

| فاز | عنوان | وضعیت | توضیح |
|-----|-------|-------|-------|
| ۰ | زیرساخت (Bootstrap) | ✅ انجام‌شده | ثبت هوک‌ها، بررسی وابستگی WC/EDD/WP، سیستم تنظیمات |
| ۱ | پنل ادمین + انتخاب تم | ✅ انجام‌شده | منو، صفحه تنظیمات، پیش‌نمایش زنده، ۶ تم |
| ۲ | استایل‌دهی خودکار | ✅ انجام‌شده | WP Core / WC / EDD با CSS متغیر |
| ۳ | بهبود UX | ✅ انجام‌شده | آواتار، ستاره، دکمه‌ها، فرم، RTL |
| ۴ | قابلیت‌های پیشرفته | 🔜 پیشنهادی | Import/Export JSON، بازنویسی اولویت‌دار، شمارنده نظرات، shortcode نمایش نظرات برتر |

### قابلیت‌های پیشنهادی برای نسخه‌های بعد (فاز ۴+)
1. **Import / Export** تنظیمات به صورت JSON
2. **Override** استایل با اولویت بالاتر (بدون نیاز به ویرایش فایل)
3. **شمارنده نظرات** استایل‌شده در کنار عنوان
4. **Shortcode** برای نمایش نظرات برتر (`[disreview_top]`)
5. **انیمیشن ورود** نظرات هنگام اسکرول (IntersectionObserver)
6. **پشتیبانی از قالب‌های کودک** (child theme overrides)
